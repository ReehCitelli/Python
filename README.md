# 🐍 Python 3 — Curso em Vídeo

Repositório com os exercícios, desafios e atividades práticas desenvolvidos durante o curso **Python 3** do [Curso em Vídeo](https://www.cursoemvideo.com), ministrado pelo professor Gustavo Guanabara.

O objetivo deste repositório é registrar minha evolução nos estudos de Python, praticando lógica de programação, estruturas básicas da linguagem e resolução de problemas.

## 📖 Sobre o Curso

O curso é gratuito e possui uma abordagem prática e didática voltada para iniciantes em programação. Além das aulas teóricas, conta com dezenas de exercícios para fixação do conteúdo, incentivando a prática constante da lógica de programação. O curso é dividido em 3 mundos com carga horária total de **120 horas**.

## 💡 Aprendizados

Durante o desenvolvimento das atividades, foram praticados conceitos como:

- lógica de programação e raciocínio computacional
- manipulação de variáveis e tipos primitivos
- operadores matemáticos e aritméticos
- estruturas condicionais e de repetição
- manipulação de strings e textos
- listas, tuplas e dicionários
- criação e organização de funções
- boas práticas de escrita de código
